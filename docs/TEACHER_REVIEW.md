# רשימה לאישור המורה

כל משפט שכתבנו בעצמנו ושתלמידים או המורה יראו או ישמעו, ושהמורה עוד לא אישרה. חומר המורה הוא המקור; כל טקסט שלנו מסומן כאן עד שהיא חותמת עליו.

**מצב:** "בכיתה היום" = הכיתה רואה את זה עכשיו. "מאחורי דגל" = מופיע רק במכשיר שהופעל בו הדגל, לא בכיתה. "עוד לא מוצג" = מוכן, אבל לא מופיע באף מסך.

איך לאשר: לסמן ✓ בעמודה "אישור / תיקון", או לכתוב שם את הנוסח המתוקן. אפשר להדפיס.

_הרשימה נבנתה מהקוד ב-26.11.2026 (js/signin.js, js/intro.js, docs/INTRO.md, js/avatar.js, js/world_data.js, js/mock.js, js/teacher.js). המסכים הרגילים של המשחק (המפה, השלבים, ההגדרות) לא נסרקו כאן: רוב הטקסטים שם קיימים מגרסאות קודמות._
